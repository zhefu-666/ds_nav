## 2. 角色职责与交接格式

| 角色 | 必须做 | 不得做 |
|---|---|---|
| Explorer | 读活动入口、调用链、参数/协议/TF/QoS；形成文件白名单与事实证据 | 修改文件、把建议写成事实 |
| Modifier | 依据白名单实现；发现事实不全先补充；更新必要适配和记录 | 无关重构、静默扩大范围、改基线默认值 |
| Auditor | 独立重读diff与关键源码，核对用户决策/权限/指标，给PASS或NEEDS_FIX | 只信Modifier自述、大范围自行修复 |

Explorer只向主Agent返回发现，由主Agent/Modifier在事后记录中整理，避免“只读Explorer写文件”的矛盾。Auditor问题交回Modifier针对修复，修复后重审。用户未授权并发写代码；可并行只读探索不相交事实。

每项交接至少包含：输入与已核对事实、允许文件、禁止范围、接口变化、检查证据、失败/依赖、产物路径。角色报告必须说明实际做过什么，不以阶段名称代替真实检查。

## 3. 先保护实车保底与运行环境

1. `git status --short`、只读哈希清单记录用户工作区，已存在修改原样保留。
2. 核对 `start.bash`、实车launch、sentry1.yaml、比赛树、communication、现有仿真入口/模型/gate。保底文件记录sha256；新增文件不自动被基线hash遮蔽。
3. 检查当前install overlay、进程/ROS域/partition/锁文件/端口；不得启动或停止不属于本次run的进程，不使用广泛pkill。
4. 后续获准构建使用独立build/install/log目录，不覆盖现有保底install；只在新终端source，记录实际解析到的包前缀/库路径。具体命令先检查当前工具支持再交用户批准。
5. 原比赛入口不改写。新入口在新包中增加，并明确选择legacy或new；新模式不能包含legacy导航服务。新旧模式不同时向同一仿真gate发布有效自动指令。
6. `docs/`受根.gitignore忽略；事后记录仍写规定目录，并在最终回复链接。正式规格/交付索引在未忽略的architecture目录。不得修改ignore或执行git add -f。对src新测试/产物也检查忽略规则并报告。

### T0：基线调查必须查到的事实

- 仿真启动参数、安装路径、ROS域、partition、机器人/场地/传感器、TF单一来源、gate输入输出。
- 活动参数来自YAML、declare、硬编码还是launch override；实车100Hz和仿真20Hz不可混用。
- 当前MPC轨迹频率推断、最近点参考、时间失效注释、Nav2返回与/cmd_vel_mpc分支。
- 当前ROGMap持有关系、PRIORMAP Nav2查询、EXPLORATION差异。
- `sim_nav_trial.py`调用NavigateToPose及navigator lifecycle；新客户端须替代，不可残留依赖导致只在旧栈上测试。
- `sim_replay_evaluate.py`是定位评分，不是通用算法回放。`sim_tunnel_passage.py`/mission可复用检查，但不能引用历史结果代替重跑。
- 权威CAD包络、接触名单、姿态/健康/倾角和物理停车评分定义；冻结为manifest，缺项保持NEEDS_FIX。

### T1–T2：必须先有负例

未知插件、重复ID、必需私人输入缺失、frame不一致、时间不递增、NaN/Inf、过期、schema不符、能力不兼容、零/非法采样周期均不能激活执行。纯类型/参数检查优先静态；行为验证在获准构建/运行后做。

worker需要请求世代与deadline；正常计划最多10Hz，整个pipeline预算80ms。有界请求策略不积压过时请求。非合作worker超时后终止/回收该run的worker并确认，不在控制线程等待；连续worker恢复失败则停止该实验。必须保留late result rejected与回收证据。

### T3–T5：禁止地图与算法比较偷换语义

现有值域不是都能原样传Kastar。公共二值碰撞掩码与软代价要分开，记录转换规则、原点/yaw、未知区/机器人膨胀。各算法接受同样障碍语义；算法无法使用软代价时声明，另报告与共同碰撞几何的关系。

Kastar C只将位置作MINCO种子，保留原始Kastar结果供分析；D保留时间并通过公共yaw处理，不暗插MINCO。速度/加速度按轴与模长分别核对，终点零速、局部目标重复停车、2D无姿态语义必须保留限制。全向反馈控制器不宣称考虑了MPC全部模型约束。

### T6：控制与兼容回归

- 从公共StateSnapshot和TimedTrajectory取样，不订阅算法私人话题决定实际执行。
- MPC时间模式与最近点兼容模式在profile中显式选择，不能把新时间戳重新当“索引步长”消耗。
- 同轨迹A/E离线对比必须锁定输入轨迹；闭环A/E会因状态反馈而产生不同轨迹，按闭环实验报告，不伪称每一时刻参考完全相同。
- 速度单位与frame显式转换一次；保留既有sim gate，不关闭健康/接触/姿态门禁以获得通过。
- yaw保持策略用于所有可比较组；另测path_tangent功能。在静止/零速点不能产生NaN或无定义朝向。

### T7–T8：可运行测试工具交付

新增工具必须提供真实 `--help`、参数校验、`--dry-run`/manifest检查、ready/goal/cleanup有界等待、run_id与输出目录、失败退出码、显式bag开关。不在本文虚构尚不存在的命令。

必须包含：检查环境与profile、启动隔离仿真、运行一个用例/全矩阵、录包停止、离线评分、结果聚合、仅清理本run进程。每个CLI实现后在人工验收文档的“命令映射表”填入经过验证的精确命令与代码行链接。新工具未实现时该表不能标为可执行。

保留全部尝试；禁止覆盖同名目录或运行脚本改变已冻结scenario。人工更改参数后重新生成manifest/hash，超预算或失败不从分母删除。

### T9：最终独立性的检查层

1. 活动进程/组件列表：新模式没有Nav2 navigator、planner/controller/smoother/behavior/waypoint/velocity/lifecycle导航宿主。
2. 服务与Action链：任务客户端不再依赖bt_navigator readiness或Nav2 BT action基类；兼容外部入口如保留需清楚标为迁移边界。
3. package.xml/CMake/include/export以及实际加载库：公共接口和最终核心插件不依赖Nav2；单纯rg无命中不足以证明库未间接链接。
4. 地图替代语义、LoadMap/切图、GoalChecker/progress、SmoothPath必要性、停用/重启职责均有实现或明确不适用理由。
5. 新旧基线和完整A-E受影响回归。过渡库依赖仍存在则DEPENDENCY_INDEPENDENT=NEEDS_FIX，允许其他分项给出真实结果。

## 5. 检查、构建和运行权限

允许先执行：rg、只读git、Python AST/XML/YAML/JSON解析、配置图与文件链接检查。不要用import带启动副作用的ROS模块来冒充静态检查，不用编译型语法检查绕过构建限制。

构建请求必须含：准确命令和包清单、为什么需要、可能触及的依赖、独立输出目录、对当前install的保护。批准后记录退出码、关键日志、失败是否由本改动引起。未批准则保存源码/静态证据并明确BUILD_NOT_RUN；不得把编译未验证标为PASS。

仿真运行授权与构建授权分开。最终启动前核对目前没有实车连接、domain/partition隔离、模型与map哈希、真值只评估、有效输出者唯一。退出时发停止/停用，确认实际停止与本run进程清理；不绕过锁或强制覆盖全局环境。

实车运动不在本执行说明默认授权内。保底实车调试若用户另行请求，应按独立任务和现场条件执行，不夹带新框架部署。

## 6. 必要状态与失败处理

框架状态：SOURCE_ONLY / BUILD_NOT_RUN / TRANSITIONAL / PASS / NEEDS_FIX。算法组合：NOT_RUN / PASS / NEEDS_FIX / BLOCKED_EXTERNAL（模型/外部条件明确）。实车：NOT_STARTED，只有另行实际验收才改变。

停止扩展本项并报告的条件：需要修改保底策略/默认值；未声明接口冲突；地图语义无法等价；必须降低门槛；所需真实模型/传感器缺失；超出三轮预算；需要未授权构建/实车动作。能完成的独立源码/静态工作继续完成，不制造总PASS。
