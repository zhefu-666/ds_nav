## 距离本轮“完整可靠仿真”还差什么

1. 历史重定位后SMAC间歇搜索失败：最终复验未重现，但根因仍未独立确认。
2. Gazebo偶发SIGKILL升级退出：任务及停车通过不代表优雅退出。需定位并验证正常退出和无残留进程。
3. 验收工具闭环：取消评分器自动纳入接触检查、统一残留进程门槛、隧道真值/净空/接触采样完整性与断流拒绝。
4. 有限已知场景之外：未知通道识别、任意路线选择、动态障碍、坡台阶、长期负载、网络/传感器/TF故障、制动延迟与距离等仍需按目标分别实现或验收。
5. 实车参数、传感器安装与底盘验收独立完成；仿真余量与安全停车结果不能直接迁移。

以上前3项是当前限定仿真验收的可靠性缺口，后2项是扩展范围，不应为了收尾重复已经无关的全部实验。
